# Router Patterns

## Pattern: Incident Triage

1. Confirm topology.
2. Reproduce symptom in that topology.
3. Select focused skill.
4. Handoff with explicit invariant.

## Pattern: Coupled Rollout Change

1. Start in `jazz-sync-architecture`.
2. Split work into runtime/loading/schema streams.
3. Route each stream to focused skill guidance.
4. Reconcile at architecture layer.
